# Security Policy

## Reporting a vulnerability

Please report security problems privately through [GitHub's private vulnerability reporting](https://github.com/LaithShareiyat/DeskStop/security/advisories/new), not in a public issue.

Include what you found, how to reproduce it, and which version of DeskStop you tested. DeskStop has one maintainer, so a reply may take a few days.

## Supported versions

Only the latest release receives security fixes.
